## Conventions later units must follow

1. **`0001_init.sql` is frozen.** `tests/Retroscope.Integration.Tests/Deploy/DeployGuardTests.cs` pins its SHA-256
   (`121cfd3e…14ed4`). Schema changes are new `0002_*.sql`+ files, quick and expand/contract-compatible with the
   previous release, because Coolify stops the old container before starting the new one.
2. **Specs against the compose stack import `tests/e2e/smoke/_stack.js`** (or copy its fixture): base URL
   `https://localhost:18443` (`RS_TEST_HTTPS_PORT`), `ignoreHTTPSErrors`, a fresh `X-Test-Client-Ip` per test,
   CSP-violation and page-error checks, and helpers to sign up, read Mailpit (`http://localhost:18025`) and verify.
   The Playwright config's default `http://localhost:8080` is not used: that port is taken on this machine, and the
   stack is https-only like production.
3. **The test stack trusts `X-Test-Client-Ip` from its proxy** (`CLIENT_IP_HEADER`). All test traffic arrives from one
   host address, so without it the per-IP limits (5 signups an hour) would throttle the suite. Production never sets it.
4. **FakeJira in the stack** answers as `acme.atlassian.net` and `api.media.atlassian.com` on an internal network,
   credentials `bot@acme.test` / `ATATT-fake-token-1234`, project `ACME`, board `1`, sprints 101 (active) and 102
   (future), issues `ACME-1`…`ACME-7` (`tests/Fakes.Host/SeedData.cs`). U45 can add scripted state through new seed
   data; the fake has no control API.
5. **Drills** live in `deploy/drills/` and share `client.mjs` (raw TLS WebSocket and HTTPS) and `tab.mjs` (cid, q,
   outbox resend, resume). U44's soak can reuse them.

## Decisions where the spec was silent or did not fit

1. **CPU split (spec gave app 0.9 and db 0.9).** Two quotas of 0.9 let our stack use 1.8 of the VPS's 2 vCPUs, which
   breaks the confirmed 1 vCPU slice. Compose cannot cap a group, so the slice is split: app 0.6, db 0.35, backup 0.05
   (the importer, which replaces the app, 0.6). Memory stays as specified (200 + 288 + 48 MiB). Locally the app peaked
   at 67 MiB and well under its CPU quota at 147 commands/s.
2. **Image references** are `ghcr.io/${GHCR_OWNER:?}/retroscope@sha256:${APP_DIGEST:?}`: a digest is structurally
   required, and Coolify blocks a deploy while a `:?` variable is empty (coolify.io docs, "Docker Compose", fetched
   2026-10-21). The release step sets the digest variable instead of editing the file. `IMPORTER_DIGEST` is not
   required, since the importer is a profile. Other secrets and `PUBLIC_URL`, `SMTP_HOST`, `SMTP_FROM`,
   `TRUSTED_PROXY_CIDRS` are also `:?`. Side effect: merging `compose.build.yml` (U0) over it needs those variables set
   to anything (RUNBOOK section 3).
3. **`GSS Encryption Mode=Disable`** in every connection string. Npgsql's default probe loads `libgssapi_krb5.so.2`,
   which the chiseled image lacks, and printed an error at every start. Our Postgres has no GSSAPI.
4. **Dynamic JSON compression is off** (§g.7 asked for Brotli Fastest over 1 KB; U11 left it to U43). Measured on the
   stack: HTML shells 2.1–3.3 KB (gzip saves 1.2–2 KB), `/api/me` 296 B, `/api/dashboard` 141 B, by-code lookups 64 B.
   Almost nothing reaches 1 KB except the shell, whose boot JSON carries per-user data next to the CSP hash, and the
   Jira proxy, whose data comes from a third party. Compressing authenticated responses that can reflect input next to
   secrets (the invite list holds decrypted invite URLs) is a BREACH risk, and on one shared vCPU the saving is not
   worth the risk. Static assets stay precompressed. The RUNBOOK tells the operator to keep Traefik's compression off.
5. **Console JSON logs are the default outside Development**, set in code (`RequestLog.AddLogging`), because the slim
   builder registers the simple formatter in code after configuration is bound, so `Logging__Console__FormatterName`
   alone was ignored (seen in the container). An explicit `Logging:Console:FormatterName` still wins.
6. **Request log and redaction.** U43 added `Hosting/RequestLog.cs`: one Information line per request
   (method, path, status, ms; no query, headers or body; `/healthz` skipped), with `/invite/<anything>` logged as
   `/invite/[redacted]`. The whole `Microsoft.AspNetCore` category is held at Warning: its hosting, routing and
   result loggers print raw URLs and redirect targets at Information (a test caught the redirect result logging the
   token).
7. **Legacy invite redirect.** §h.6 promises `/invite/:token` → `/invite#t=:token` and nothing implemented it.
   `Hosting/LegacyInvite.cs` answers 302 with `Cache-Control: no-store`, using `Response.Redirect` because
   `Results.Redirect` logs its location.
8. **Key rotation entry point.** `Credentials.RotateAsync` had no caller and `Program.cs` is frozen.
   `Jira/CredentialRotation.cs` runs it once at start on the leader whenever `APP_KEYS` lists more than one key, which
   is exactly the window in which old boxes can exist. A single-key keyring skips it, so ordinary starts do nothing.
9. **HSTS on HTML over https is confirmed end to end**: through Traefik's TLS, `/` and `/login` carry
   `strict-transport-security: max-age=63072000; includeSubDomains` (`tests/e2e/smoke/shell.spec.js`), besides U11's
   integration tests.
10. **FakeJira container** (carried follow-up). `tests/Fakes/FakeJira/**` belongs to UF12 this wave, so it is used
    unchanged: `tests/Fakes.Host` (new) starts it on loopback and fronts it with TLS on :443 under a certificate from a
    throwaway CA generated at start. The CA plus the system roots is written to a shared volume, and the app trusts it
    through `SSL_CERT_FILE`. The Jira client refuses private addresses by design (§f) and has no override, so the fake's
    network is `internal` with the publicly routable subnet `198.20.89.0/24`; nothing leaves that network. The project is
    not in `Retroscope.slnx` (U0's): it is built by `deploy/Dockerfile.fakes` whenever the stack starts, and only the e2e
    stack uses it.
11. **TLS proxy in the test stack.** Session cookies are `__Host-` and always `Secure`, HSTS is only sent for an https
    `PUBLIC_URL`, and production sits behind Coolify's Traefik. So the stack serves https through Traefik v3.7.16
    (Docker Hub digest pinned 2026-10-21) with its default self-signed certificate, and the smoke specs pass on all four
    browser projects that way. Whether every browser would accept `Secure` cookies over plain http to localhost was not
    tested. This also exercises WebSocket pass-through and forwarded headers as Coolify does. Traefik's file provider runs with `watch=false` and the fake host with
    `DOTNET_hostBuilder__reloadConfigOnChange=false`: both otherwise hit this machine's shared inotify limit (U0 decision 14).
12. **`pull_policy: build`** on the two built services, so `./build.sh e2e` (which runs `up --wait` without `--build`)
    never tests a stale image.
13. **PG18 `PGDATA`** is `/var/lib/postgresql/18/docker` (checked in the running container: `show data_directory`),
    inside the `/var/lib/postgresql` volume; data checksums are on; server 18.6.
14. **Unowned paths created by U43**: `tests/e2e/smoke/**` (the Check's spec glob; no unit owned it),
    `deploy/drills/**`, `deploy/Dockerfile.fakes{,.dockerignore}`, `tests/Fakes.Host/**`,
    `tests/Retroscope.Integration.Tests/Deploy/**`, `tests/Retroscope.Integration.Tests/Hosting/RequestLogTests.cs`,
    `tests/Retroscope.Integration.Tests/Jira/Client/CredentialRotationTests.cs`, and the new
    `src/Retroscope.Server/Hosting/{RequestLog,LegacyInvite}.cs` and `src/Retroscope.Server/Jira/CredentialRotation.cs`.
    **Edits to files other units own** (each one line, all needed by the carried follow-ups addressed to U43):
    `Hosting/HostingModule.cs` (U11: register the request log, use it first in the pipeline, map the legacy redirect)
    and `Jira/JiraClient.cs` (U19: register `CredentialRotation`).

## Amendment (UF15)

1. `RequestLog.Redact(path, rawTarget)` redacts any path that starts with `/invite` (any case) and has anything after
   it, judged on the raw request target and on `Request.Path`, each also percent-decoded (up to four layers) and with
   dot and empty segments removed. `/invite%2F<token>`, `/invite/%2e%2e/…`, `//invite/…` and `/x/../INVITE/…` are all
   logged as `/invite/[redacted]`; so are `/invite/` and `/invites/…`, which the old segment rule let through.
   `/invite` alone (the invite page) is still logged as is.
2. `./build.sh e2e` exports `RS_E2E_BASE_URL=https://localhost:${RS_TEST_HTTPS_PORT:-18443}`, and the Playwright
   config's fallback is now `https://localhost:18443` (convention 2 no longer needs to say the default is unused).
