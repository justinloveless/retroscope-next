# U14 decisions: WebSocket transport

U14 owns `src/Retroscope.Server/Realtime/Transport/**` and its tests in `tests/Retroscope.Integration.Tests/Transport/**`
(the Check runs `Category=Transport`; §k names no test path, so the folder follows U11's `Hosting/**` precedent).

## Contracts later units rely on

| Type | Use |
|---|---|
| `IRoomGateway` | What the transport hands to the actor runtime: `Subscribe(conn, room, e, s)`, `Unsubscribe`, `Command(conn, CmdFrame)`, `Disconnected(conn, rooms)`. Called on the connection's receive loop; must never block it (R26). **U13 implements it and registers it in `ActorsModule.AddServices`** (which runs before `TransportModule.AddServices`, whose `TryAdd` then keeps U13's) |
| `IClientConnection` | A socket as actors see it: `Viewer`, `AuthSessionId`, `Send(ServerFrame)`, `Send(ReadOnlyMemory<byte>)`, `Send(segments)` (one message from a shared snapshot document plus an overlay, R11), `Kick(room, code)`, `Restart()` (bye + 1012). Thread-safe, non-blocking. `Send` returns false once the socket is closing or has just overflowed (4008) |
| `ConnectionRegistry` | Implements `IConnectionRevoker` (registered as such). `ConnectionsOf(principal)` lists the principal's live, hello'd connections (for `presence.update` after a rename, §c.4). `DrawRetryMs()` / `RetryWindowMs(n)` |
| `TransportOptions` | Every limit and timing; production uses the defaults |

Until U13 lands, `UnavailableRoomGateway` serves no rooms: every `sub` is kicked `not_found` and every command nacked
`not_subscribed`.

## Decisions where the spec was silent or did not fit

1. **Refusals the client must tell apart are close codes on an accepted socket.** A browser cannot read the HTTP status
   of a failed upgrade, so a bad or missing `Origin` (4403), the per-IP socket cap (4429) and an upgrade that raced
   past the shutdown check (1012) accept the socket and close it at once without sending a frame. Requests that cannot
   be a legitimate tab are refused over HTTP before the upgrade: no caller → 401 (the route policy, `RoutePolicy.Guest`),
   shutdown begun → 503, a plain GET → 400. `Origin` must be exactly one header equal to `PUBLIC_URL`'s origin,
   compared ordinally like the CSRF filter; `Origin: null` and a missing header are refused.
2. **Over the per-IP socket cap is 4429.** §c.3 lists no code for it; "rate limited" is the closest and makes the
   client back off.
3. **Upgrade rate limit** (`ws`): 120/min per IP and 30/min per principal (S7). After a restart every tab reconnects
   once inside `bye.retryMs`, and the client backs off exponentially, so neither limit is reached by real tabs.
4. **The rate limit counts every inbound frame after `hello`**, not only `cmd` (§c.7 says "commands"): a flood of
   `ping` or `sub` is the same abuse. A refused `cmd` is nacked `rate_limited` (retryable); a refused frame of another
   type is dropped. **"Sustained abuse for 10 s"** is a refusal streak: refusals less than one second apart continue the
   streak, and a streak that lasts the abuse window closes with 4429. A client sending faster than 20/s is refused some
   frames every second and is closed after 10 s; a single burst is only nacked.
5. **`bye.retryMs` window.** Drawn uniformly from 500 ms to `min(8000, 500 + 15 ms × live sockets)`: 515 ms for one
   socket, 2 s at 100, the full 8 s from 500 (the §i.3 socket budget), so reconnects arrive at ≤ ~65/s.
   **The transport, not the actors, sends `bye`.** It is per connection while actors are per room: a socket subscribed
   to three rooms would get three byes with different `retryMs`. Actors call `IClientConnection.Restart()` (fencing loss,
   outcome-unknown commit) and the `CloseSockets` shutdown step restarts every socket. U13's `DrainActors` step only
   needs to finish commands and persist spotlight positions.
6. **Shutdown steps** (U11 follow-up): `StopAccepting` makes the registry refuse new connections (closing the gap
   between the `IsStopping` check and registration), and `CloseSockets` sends `bye` + 1012 to every socket and waits
   until each has closed or been aborted (`CloseTimeout`, 2 s). Both are registered in `TransportModule.Map`, the
   first point where the frozen `Program.cs` hands over the built service provider.
7. **`cid_in_use` (4409).** A cid is refused while another live connection holds it, or when it was last bound to a
   different principal. The second rule is in memory: an LRU of the last 16,384 cids (about 1 MB). The durable binding
   is `client_cursors.principal_id`, which the actor checks per room (`forbidden`, U12).
8. **What closes the socket and what is nacked.** Frame over 64 KiB → 4413 (also before `hello`). Any frame before
   `hello`, a second `hello`, `v != 1`, a binary frame, or an envelope the parser rejects → 4400. A `cmd` whose envelope
   parsed but whose kind or payload did not (`UnknownKind`, `WrongRoom`, `InvalidData`) is nacked `invalid` with the
   parser's message (member and kind names only, S33), so version skew costs one command, not the socket. A `cmd` for
   a room the connection has not subscribed to (or was kicked from) is nacked `not_subscribed` without reaching the
   actor.
9. **Room cap.** The eleventh distinct room is kicked `too_many_rooms` (U2 kick code) and never reaches the gateway; a
   re-`sub` of a room already held is passed on (resume).
10. **Outbound queue.** Unbounded channel plus a byte counter; bytes count from enqueue until `SendAsync` has taken
    them, so a client that stops reading overflows even though TCP buffers absorbed the first megabyte. Overflow
    closes with 4008 and drops everything still queued; the close frame follows the frame in flight, and the socket
    is aborted if the close handshake does not finish within `CloseTimeout`. Every other close (bye + 1012,
    protocol violations) is queued behind the frames before it.
11. **Receive buffer** is 4 KiB per socket (U11 decision 16). A frame that arrives in several reads is assembled in a
    64 KiB buffer rented from the shared pool and returned at once, so idle sockets hold only the 4 KiB.
12. **No permessage-deflate** (`DangerousEnableCompression = false`, §c.3).

## Verification

- `dotnet test tests/Retroscope.Integration.Tests --filter Category=Transport`: 61 tests pass on real Kestrel over
  loopback (six consecutive runs). Mutation checks (Origin check off, keep-alive timeout infinite, cid rules off,
  per-IP cap ×100, outbound cap ×1000, abuse close off, revocation code changed, hello timeout ×100, room cap ×2,
  frame cap ×2, bye removed) each fail at least one test.
- **PING/PONG under Native AOT (§12 row).** `./build.sh aot-smoke` publishes the server, transport included, with zero
  AOT/trim warnings. `aot-smoke` is U0's and does not exercise sockets, so the behaviour was checked with a throwaway
  AOT console (not committed, like U2's) that compiles the real `Hosting/**` and `Realtime/Transport/**` sources: a
  client that sends nothing but answers PINGs stayed connected through 3 s of 200 ms PINGs and then got its pong,
  and a raw TCP peer that never answers was aborted after interval + timeout. Result on osx-arm64 (Mach-O native
  binary, zero publish warnings): "silent client alive after 3 s of 200 ms PINGs: True", "dead peer aborted: True
  after 675 ms" (interval 200 ms + timeout 500 ms). **Verified.**

## Follow-ups for other units

- **U13:** implement `IRoomGateway` and register it in `ActorsModule.AddServices`. Fan out with
  `IClientConnection.Send`; serialize a shared document once and pass it to every subscriber as one segment of
  `Send(segments)` (the transport never mutates or pools caller memory). On fencing loss or an outcome-unknown commit
  call `Restart()` on each subscriber instead of writing `bye` yourself. A `Send` that returns false means the socket
  is going away; `Disconnected` follows.
- **U16:** `IConnectionRevoker` is registered by `TransportModule.AddServices`; resolve it, do not register another.
  `Caller.AuthSessionId` must be set for user cookies, or `RevokeAuthSession` cannot find the session's sockets.
- **U0 / `build.sh` owner:** `aot-smoke` could run the native server's `/ws` PING/PONG check once U16's cookie auth
  exists (today every real-server upgrade is anonymous and refused with 401).
- **U28:** the server closes refused upgrades with 4403 (Origin), 4429 (socket cap or abuse) and 1012 (shutdown race).

## Amendment (UF7)

1. **Hello and the hello timer are mutually exclusive.** Both race for one state flag with `Interlocked.CompareExchange`
   (pending → accepted, or pending → expired). A timer that wins closes 4400 and no welcome follows; a hello that wins
   sends welcome, and a timer callback that was already running does nothing. Before, a timer that fired while `Hello`
   ran could close 4400 right after the welcome.
2. **Timers.** The abort timer is created (in `Close`, any thread) and disposed (at the end of `RunAsync`) under one
   lock, and `Close` arms none once the connection has ended. Before, a `Restart` or kick after a peer vanished created
   an abort timer nobody disposed. `_viewer` is written and read with `Volatile`, since actors read `Client` and
   `Viewer` from their own threads.
3. **Tests** drive a `Connection` over a loopback socket pair with a fake clock (`HelloRaceTests`): 200 races of hello
   against the timer, a late hello after the timer, the timer after a hello, and a count of live timers after the
   connection ended.

## Amendment (UF9)

1. **No placeholder gateway.** `UnavailableRoomGateway` is gone; the actor runtime always registers `RoomGateway`.
2. **`rate_limited` refusal.** After a command is refused `rate_limited`, every later command of that room on the
   connection is refused `rate_limited` until the client subscribes to the room again, and that `sub` is never dropped
   by the limiter (UF9 decision 1).
3. **Hello timer.** Re-checked; the UF7 rule (one flag, `CompareExchange`) leaves no window, so nothing changed.

## Amendment (UF13)

1. **The `sub` that lifts a `rate_limited` refusal borrows its token** (`ConnRateLimit.Take(borrow: true)`, at most one
   burst of debt) instead of passing the limiter for free, so repeated subs cannot fetch snapshots beyond the
   connection's rate. It is refused only once the connection is already a burst in debt (UF13 decision 1).
2. **`IClientConnection.Holds(room)`**: open, subscribed, and not kicked or unsubscribed since. The actors use it so a
   queued subscribe never outlives the connection's record of the room (UF13 decision 2).
3. **Tests.** `Wait.Default` is 60 s. `LivenessTests` uses a 1.5 s keep-alive timeout (100 ms interval) and
   `HandshakeTests` a 1.5 s hello timeout, each waited out twice, so a starved test process still answers in time.
