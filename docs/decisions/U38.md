# U38 decisions: importer source, preflight, archive, CLI

U38 owns `Importer/{Program.cs,Source/**,Archive/**}`, `Importer/Map/{expected-columns.json,Common.cs}` and
`tests/Retroscope.Importer.Tests/Infrastructure/**`.

## Public surface (for U39, U40, U41, U42)

| Type | Use |

## Decisions where the spec was silent or did not fit

1. **Two files outside the owned paths.** `src/Retroscope.Importer/Retroscope.Importer.csproj` gains one
   `EmbeddedResource` item (`Map/*.json;Source/*.json`): the importer image has no data files, and §h.1 requires
   `expected-columns.json` at run time. Nobody owns the csproj; the change is one line and needed by every later
   importer unit. The test project's csproj is unchanged: the fixture finds its SQL files by walking up to
   `Retroscope.slnx`.
2. **Where the orchestration lives.** §k gives U38 no folder for it, so `Source/ImportRunner.cs` runs the verbs and
   `Source/TargetDatabase.cs` holds the target-side steps (fence, truncate, cutover). `Archive/` holds everything
   that writes `archive.*`, including the phase 5a staging (`StorageCache`), because its check is in U38's list and
   its table is `archive.storage_cache`. U42 owns the in-transaction storage phase (`Storage/**`).
3. **`expected-columns.json` format.** Per table: `disposition` (`map`, `archive`, `exclude`, `manifest`),
   `primaryKey`, `columns` (name → `pg_type.typname`, `enum` for enums), and lists: `archive` (to
   `<table>#dropped`, or `#meta` via `archiveSuffix` for `auth.*`), `seal`, `omit` (never read: Jira titles,
   ephemeral spotlight and timer state, the `votes` counter, generated columns), `html` (histogram input) and `plain`
   (exempt from the name-regex backstop: `app_config.key`, `poker_ticket_queue.ticket_key`). `allowArchiveOnly` is
   the operator's list of `schema.table` / `schema.table.column` entries that may appear without failing; they are
   archived. The file was generated from the fake source below and then classified by hand against §h.2.
4. **Preflight reads `pg_catalog`, not `information_schema`.** `information_schema.columns` hides columns the
   connecting role has no privilege on, so a read-only role could make an unknown (possibly secret) column
   invisible. A test proves a column-level-restricted role still trips preflight.
5. **Scope of the `auth.*` rule.** Every column of an `auth` table we read (`users`, `identities`) must be listed:
   an unlisted one fails even when allow-listed (S25). Excluded `auth` tables are only counted, so their columns
   are not compared. An `auth` table the file does not mention at all (GoTrue adds internal tables such as
   `instances`, `sso_providers`) is never read and produces a warning, not a failure. `storage.objects` only
   requires `id, bucket_id, name, metadata`; its other columns are ignored, since no other column is read.
6. **Type and key changes fail too.** A column whose type changed, or a table whose primary key changed, fails
   preflight. Composite keys are joined with `|` for `source_pk` (§b).
7. **The snapshot is read-only by statement.** Npgsql's `BeginTransaction(RepeatableRead)` cannot say READ ONLY,
   so `set transaction read only` is the transaction's first statement (tested: an insert fails with 25006).
   Unmapped types are selected as `::text`.
8. **Fingerprint.** `pg_control_system()` is read before the snapshot, because a managed host may refuse it and the
   failure would abort the snapshot. When refused, the system identifier is empty in the hash and `null` in the
   report.
9. **TLS default.** `IMPORT_SOURCE_PG` gets `SSL Mode=VerifyFull` unless it names an SSL setting itself. Both
   connection variables accept `postgres://` URIs.
10. **Same-database guard.** Same host (case-insensitive), port and database name means refuse.
11. **Fence.** `run` takes the lease with `pg_try_advisory_lock(0x52455452)` on its own unpooled target
    connection and keeps it for the whole run (an app starting mid-import cannot become leader), retrying for 10 s
    and then refusing with "stop the app". With the lease held it bumps `leader_epoch` under
    `pg_advisory_xact_lock(1381123153)`, which waits for any in-flight fenced transaction. `leader_instance` is the
    run id.
12. **Timeouts.** Besides the owner role's 0 timeouts (U1), every importer target session runs
    `set statement_timeout = 0; set idle_in_transaction_session_timeout = 0; set lock_timeout = 0`, and the main
    transaction repeats `set local statement_timeout = 0`. The test sets 500 ms database-level defaults and holds
    a 1.5 s statement plus 1.5 s of idle time inside the main transaction.
13. **Run bookkeeping.** `archive.import_runs` gets a `running` row in its own transaction after the fence; success
    is written inside the main transaction, failure (with the exception message in `facts.error`) after the
    rollback. The main transaction truncates every `public` table except `schema_migrations` and `system_state`,
    plus `archive.rows`, `archive.storage_objects` and `archive.excluded_tables`, never `archive.import_runs` or
    `archive.storage_cache`.
14. **Seal coordinates.** A sealed value's AAD uses the archive row's own `source_table` (including the `#dropped`
    or `#meta` suffix), its `source_pk` and the column name, so the operator opens it from what is stored next to
    it. `report.facts.seal` carries `keyId` and the base64 `wrappedKey`, or `{"stripped": true}`.
15. **What goes to `#dropped`.** Each kept table's `archive` list, written for every source row with at least one
    non-null value in it, whether or not the mapping imported the row. `auth.users#meta` holds the metadata and
    the sealed token and phone columns; `encrypted_password` is in the `seal` list but not in `archive`, so it is
    sealed only when U39 archives a merged or dropped account. `retro_boards.password_hash` (the old board password) is
    archived sealed.
16. **Duplicate-email tie-break.** Latest `last_sign_in_at` (null counts as oldest), then earliest `created_at`,
    then smallest id as text, so re-runs agree.
17. **Display-name scrub.** "Email-shaped" means the name contains `local@domain.tld`. The replacement is
    `Guest-` + the first four hex digits of SHA-256 of the lower-cased name; names are trimmed, capped at 60
    characters, and an empty name becomes `Guest`.
18. **Synthetic namespaces** (frozen): guests `6f1c2a8e-3b5d-4e7a-9c41-2d8b7e5f0a13`, Slack
    `b2e94d17-8a60-4c3f-a5d2-91f7c03e6b48`; names are `guest:<key>` and `slack:<key>`.
19. **HTML policy.** Converted: §h.4's list. Dropped: `script`, `style`, `iframe`. Text-only by default:
    `span u mark sub sup small font del ins h1–h6 hr` (TipTap's StarterKit emits headings and rules; mentions are
    spans). Tables are deliberately not text-only, so a pasted table fails `plan` until the operator decides.
    Attributes are counted and reported, never a failure.
20. **Storage staging.** Candidates are objects in bucket `avatars` named `<uuid>.<ext>` whose uuid is a kept user
    (the original uploaded `<user id>.png`), plus `profiles.avatar_url` values on `https://lhN.googleusercontent.com`
    (default port, no userinfo) for kept users, cached under bucket `google` with the URL as path. Public objects
    are fetched from `IMPORT_STORAGE_URL` (a new variable: the pooler URI does not name the project's HTTPS host)
    + `/storage/v1/object/public/<bucket>/<name>`, without redirects. "Already cached" means the (bucket, path)
    pair exists: the sha256 is only known after downloading. Skipped objects are printed; U42 records them in
    `archive.storage_objects`.
21. **`plan` and `verify`.** `plan` runs preflight, the snapshot counts and the histogram and prints the report
    JSON; it writes nothing. Dry-run mapping counts belong with the mapping stages (U42 can run the stages in a
    rolled-back transaction). `verify` runs every `IVerifyCheck` in a read-only transaction; with no checks yet it
    reports 0 failures.
22. **Exit codes.** 0 success, 1 a refused or failed run (message on stderr), 2 usage.

## The fake Supabase source (tests)

`tests/Retroscope.Importer.Tests/Infrastructure/Supabase/` builds a template database once per run:

1. `00-platform-stubs.sql`: roles, `auth.users`/`auth.identities` as in
   `orig/server/postgres/init/02-auth-schema.sql` plus GoTrue's generated `confirmed_at` (**unverified** against a
   live project; an extra or missing `auth.users` column fails `plan` safely, which U46 checks on production), the
   other `auth` tables as minimal stubs, `storage.buckets`/`storage.objects`, `cron.job`.
2. `schema-dump-99b8c3a.sql`: verbatim copy of `scratchpad/understand/_schema_dump_99b8c3a.sql`.
3. `migrations/*.sql`: verbatim copies of `orig/supabase/migrations` (commit `7f48a79`). Twelve fail on top of the
   dump because the dump already contains them; `ImporterDatabases.InDump` names them and they are skipped.
4. `90-foreign-tables.sql`: `consultation_requests` and `github_installations` from `types.ts` (no migration
   creates them), plus one `cron.job` row.
5. `95-baseline-rows.sql`: the default tenant (`set_tenant_id()` stamps it on new rows, and those columns are FKs).

The resulting public schema equals `types.ts` table for table and column for column, except
`team_action_item_comments`, which `types.ts` omits (schema.md §0). Seeds that insert into tables with Supabase
triggers (`teams` adds the creator as a member through `auth.uid()`) use `session_replication_role = replica`.

The targets are migrated by applying `db/migrations/*.sql` directly as the container superuser, not through the
Server's `Migrator`: the importer tests do not reference `Retroscope.Server`, and the importer must not depend on
the app role, its grants or its role-level timeouts (decision 12 covers the latter explicitly).

## Amendments (UF4)

- **Decision 5 changes: an unlisted `auth` table fails preflight** (S25), even when it is allow-listed. Archiving an
  `auth` table would copy its secrets without sealing them, so `allowArchiveOnly` never covers `auth.*`. The operator
  adds the table to `expected-columns.json` instead, as `exclude` (counted, never read) or as `map` with its sealed
  columns. `auth.instances` (GoTrue's legacy configuration table, which the fake source has) is now listed as
  `exclude`. Other GoTrue tables that a production project may have (`schema_migrations`, `sso_*`, `saml_*`,
  `oauth_*`, depending on the GoTrue version) are **unverified**. `plan` against production (U46) names any that are
  missing, and each one becomes an `exclude` entry. `PreflightResult.Warnings` and the `preflightWarnings` report list
  are gone, because nothing produces a warning any more.
- **`--html-textonly <path>`** (for `plan` and `run`, and accepted by every verb) reads a file with the same shape as
  `html-textonly.json` and adds its tags to `HtmlTagPolicy.TextOnly` for the rest of the process. The built-in tags
  stay. The histogram and U41's converter both read `TextOnly`, so they agree. A tag that is already converted or
  dropped, a name that is not a lower-case tag name (`[a-z][a-z0-9-]*`), or an unreadable or malformed file refuses
  the run (exit 1). `HtmlTagPolicy.TextOnly` is now a property that returns the current set; it was a get-only
  auto-property, and callers do not change.
- **The importer csproj's `EmbeddedResource` line (decision 1) is accepted.** UF4 owns the csproj now, and the line
  stays as it is.
