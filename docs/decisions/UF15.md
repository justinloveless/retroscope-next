# UF15 decisions: wave 6 follow-ups

Spec: `docs/followups/UF15.md`. Amendments to U27, U43, UF13 and UF14 point back here.

## Decisions where the spec was silent or did not fit

1. **What "under `/invite`" means.** The spec's rule is taken literally: a path that starts with `/invite` (any case)
   and has anything after it is redacted, so `/invite/`, `/invites/…` and `/invite;…` are too. Nothing the app serves
   needs those logged, and a narrower rule is what let `/invite%2F<token>` through. Each form is checked raw and with
   dot and empty segments removed, then percent-decoded and checked again, up to four layers (`%252F` decodes twice).
   A deeper encoding is not a usable invite link, so it is logged as is. The raw request target is checked as well as
   `Request.Path`, because Kestrel normalises the path (dot segments) but keeps `%2F` encoded; an absolute-form target
   (`http://host/invite/…`) is reduced to its path, and the query is ignored.
2. **Admin owner change for a non-member.** `TransferOwnership` needs the new owner to be a member, so a non-member is
   added as a member first (its own ask and audit row) and then given ownership. Both steps leave the team with
   exactly one owner. If the transfer then fails, the person stays a plain member, which an admin can undo. A
   transfer the decider refuses because the owner changed or the target left since the roster was read answers
   409 `conflict`. Any other refusal (a database failure surfaces as `internal`) keeps the existing mapping.
3. **The admin audit** is one `admin.team.owner.transfer` row instead of two `admin.team.member.role` rows, matching
   the team endpoint's `team.owner.transfer`.
4. **The Stopwatch fallback is not a test.** Whether libc loads depends on the image, so a test that demanded the CPU
   clock would fail exactly where the fallback is meant to keep the suite running. The Linux check was a one-off
   container run, recorded in the UF13 amendment.
5. **Client watchdog backoff.** Each unanswered retry sub raises the attempt count, so the gap grows from 500 ms to the
   5 s cap. An answered sub does not raise it, so U28's existing backoff sequence is unchanged.
6. **Playwright base URL fallback.** Besides the `cmd_e2e` export, the config's fallback moves from
   `http://localhost:8080` to `https://localhost:18443`, so a direct `npx playwright test` with
   `RS_E2E_TARGET=compose` reaches the same stack. U48's decision still names the old default; that file is not in
   UF15's append list.
7. **Pinned zone and locale** are spread after each device descriptor, so no device can override them.
