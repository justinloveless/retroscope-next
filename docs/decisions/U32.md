## Decisions where the spec was silent

1. **Navigating when the strip settles** (§g.8, F19) happens only after a user gesture on the strip (wheel,
   touch, pointer press). Scrolls the page starts itself (centring the viewed chip, layout shifts, font swaps) never
   navigate; when one leaves the viewed chip off centre it is centred again. A smooth scroll the page started is
   only "settled" once it reaches its target (or after 1 s), because a slow frame or an interrupting `scrollTo`
   looks like a pause. `data-settle` on `.nt-strip` says which path the browser uses (`scrollend` or a 120 ms
   `scroll` debounce).
2. **Wheel.** A vertical wheel moves one chip per 100 px of delta and scrolls smoothly to it; horizontal deltas
   stay native. Snapping is mandatory, so small programmatic `scrollBy`s would snap back to the same chip.
3. **Clicking a chip** navigates at once (no wait for the scroll); the context menu's Move left/right share the
   reorder path with the grip. Delete asks for confirmation. Delete is offered to team admins and owners (role from
   `/api/me` `teams`) and to signed-in users of quick sessions (§c.4); the server decides anyway.
4. **Reorder** is optimistic (§g.4) and reads the room's live view, not the last render, because two key presses
   can land in one animation frame. A `stale` nack rebases once through U28's `rebase`: the moved round goes to
   the index the user chose among the fresh rounds. Touch needs a 300 ms press without moving more than 8 px;
   moving earlier abandons the press (the grip has `touch-action: none`, so no scroll is lost). The strip
   auto-scrolls near its edges while dragging.
5. **"+" and "▶".** The original's toolbar centre held "New round" and "Next active round"; U31 owns that toolbar,
   so both buttons sit at the end of the strip. "New round" sends `poker.round.create` without `forceNew` (fill
   the placeholder, parity).
6. **Spotlight roles.** `spotlightRole` is `none`, `other`, `bound` (this tab drives it), `mine` (I hold it, no tab
   is bound, e.g. after a give or after the bound tab's grace) or `elsewhere` (a move from this tab was refused
   `not_holder`). A `mine` tab binds by moving on its next navigation (the server binds `HolderClient` when null).
   `elsewhere` covers U31's stale `heldByThisTab` case too: it sticks until the holder changes, this tab claims the
   spotlight, or it force-takes. "Take spotlight" always sends `force:false` first and shows "Take spotlight?" on
   `spotlight_held` (from the room's per-send `onNack`), so a stale view never skips the confirmation.
7. **Moves trail by 150 ms**: the first navigation starts a 150 ms timer and the move carries wherever the tab is
   when it fires, so stepping through rounds sends one move.
8. **Settings** keep a Save/Cancel dialog (parity). Only changed fields are sent, each with the value the dialog
   opened with as `expected`. Observer checkboxes are sent as one `poker.observer.set` per changed principal on
   Save. "Delete all rounds" sits in a Danger zone with the same rights as Delete round.
9. **History** lists rounds in strip order: winner (or "No points"), "Revealed by X · HH:MM" or "Revealed
   automatically · HH:MM", a Jira line (story points, a pending or failed submit), "Voting", "Preview" or "Ended
   without a reveal". An entry opens its round.
10. **Round change animation.** §g.8's 280 ms two-pane slide is drawn as the incoming table sliding in from 30 %
    on the side it came from (WAAPI on `.nt-center`), on every viewport. A real two-pane slide would need a copy
    of the outgoing table, which U31's table does not offer. Reduced motion turns it off.
11. **Swipe** uses Pointer Events (pointerType touch or pen) on the table area with `touch-action: pan-y` on
    phones, so vertical scrolling stays native and a horizontal swipe never gets `pointercancel`. Swipes that
    start on the hand, a field or the drop overlay are left to those controls.
12. **No issue-type glyph yet.** Chips show a tag icon; `ui/glyphs.js` is U33's and does not exist on main. U33 or
    the integrator can swap `icon('tag')` for the glyph of `room.extras['jira.meta'][key].issueType`.
