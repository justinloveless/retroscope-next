- `src/Retroscope.Core/Team/**`

1. **Security: deleted teams stay deleted.** The `MembershipCache` member query joins `teams` with `deleted_at is null`. After a restart, or after `Forget(team)`, a soft-deleted team's members have no access to its sessions or boards. Add a test that restarts the host.
2. **Atomic ownership transfer.** A single `TeamInput.TransferOwnership` demotes and promotes in one actor transaction. A crash can never leave a team with no owner. `TeamsEndpoints.TransferAsync` uses it.
3. **Security: Jira link delete is scoped.** Deleting a link checks that the link belongs to the issue in the route, using the issue's own link list. Otherwise it returns 404. Make FakeJira evaluate the JQL subset the app sends (project, sprint, status category, text search, order by rank), so the browse filters are really tested.
4. **Fenced retention and team purge.** Each delete batch commits through the leader fence. A server that loses leadership mid-pass stops deleting.
5. **Purge without starvation.** A pass that finds its candidates all subscribed moves on, keyset-paginating past them, so other idle rooms still get purged.
6. **Indexed team-purge lookup.** The `recent_activity` team-purge query uses an index-friendly predicate, adding a 0002 migration if an index is needed. Prove it with EXPLAIN on the repo's real SQL.
7. **Spot-load in the importer tests.** `SpotLoadTests` (importer) call U27's `SpotLoadCommand`.

**Check:** `dotnet test tests/Retroscope.Integration.Tests --filter "Category=TeamRoom|Category=TeamHttp|Category=JiraHttp|Category=Admin"` and `./build.sh test` green. Items 1–5 each have a test that fails on the old code.
