# UF13: realtime and auth edge cases, load-robust timing tests (from wave 5)

UF13 owns:
- `src/Retroscope.Server/Realtime/{Actors,Transport}/**`
- `src/Retroscope.Server/Auth/**`
- `src/Retroscope.Server/Endpoints/{MeEndpoints,AuthEndpoints}.cs`
- `src/Retroscope.Server/Data/Repos/{Users,Blobs}Repo.cs`
- `tests/Retroscope.Sim/**`
- the timing-sensitive tests named below
- `docs/decisions/{U13,U14,U16,U17,UF9,UF10}.md` (append-only)

1. **Subscribe rate limit.** Repeated `sub` frames cannot fetch snapshots beyond the connection's rate limit. Test it.
2. **Kicked-connection subscribe.** A subscribe queued while the same connection is being kicked never leaves a subscription the connection does not track. Test it.
3. **Twins fault class.** Fix the remaining "Twins" failures (2/2000 seeds), then enable Twins in the default fault set.
4. **Avatar upload.** Inserting the avatar blob and setting `users.avatar_blob_id` happen in one transaction, with no orphaned blobs.
5. **Magic-link verify.** The verify check reads authoritative state, never a possibly stale cache.
6. **Load-robust timing tests.** These tests must stay meaningful under load:
   - `AdfCapsTests.Hostile_shapes_convert_quickly`
   - `MarkupJiraLengthTimingTests`
   - `LoginTests.Unknown_email_costs_as_much_as_a_wrong_password`
   - the realtime liveness, presence, ring and outbound timing tests

   Make them pass under load without losing what they prove. Measure work (operation counts, linear-scaling ratios between n and 4n, relative comparisons within one run) instead of absolute wall-clock thresholds. They must still fail if an algorithm is made quadratic or the timing parity is removed.

**Check:**
- `dotnet test tests/Retroscope.Integration.Tests --filter "Category=Actors|Category=Transport|Category=AuthCore|Category=Email"` passes.
- `dotnet run --project tests/Retroscope.Sim -- --seeds 2000 --strict` passes with Twins on.
- `./build.sh test` passes twice in a row with bounded background load: at most 4 `yes > /dev/null` processes, each started with `nice -n 19`, all killed when the runs finish (trap on EXIT). Never one per core: the host is the user's workstation and other agents share it.
